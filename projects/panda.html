The Problem: Robotic Manipulation Beyond Scripts

Robotic pick-and-place tasks appear deceptively simple, yet they expose many of the fundamental challenges in manipulation: high-dimensional control, kinematic constraints, perception uncertainty, and the need for precise, repeatable interaction with the environment.

Classical approaches solve structured scenarios reliably, but require careful system integration and often fail to generalize beyond explicitly modeled cases.

Step 1: Classical Pick & Place Pipeline

The initial system was built using a classical robotics pipeline based on explicit modeling and modular decomposition.

  • HSV-based cube detection and centroid estimation
  • TF-based coordinate transformation into robot base frame
  • Sampling-based motion planning (RRTConnect)
  • Jacobian-based inverse kinematics using Pinocchio
  • Explicit sequencing of approach, grasp, lift, and retreat

Perception: HSV Filtering and Object Localization

Object detection is performed using simple HSV color segmentation to maintain transparency and robustness under controlled lighting.

RGB images are converted into HSV space and thresholded:

$$ M(x,y) = \begin{cases} 1 & H_{min} \le H(x,y) \le H_{max} \\ 0 & \text{otherwise} \end{cases} $$

Binary masks are processed using contour detection. The object centroid is computed using image moments:

$$ c_x = \frac{m_{10}}{m_{00}}, \quad c_y = \frac{m_{01}}{m_{00}} $$

The centroid is then projected into 3D and transformed into the robot base frame using ROS 2 TF.

Inverse Kinematics with Pinocchio

For the 7-DoF Franka Panda arm, forward kinematics define a mapping:

$$ \mathbf{x} = f(\mathbf{q}) $$

The differential relationship between task space and joint space is:

$$ \dot{\mathbf{x}} = \mathbf{J}(\mathbf{q}) \dot{\mathbf{q}} $$

A damped least-squares inverse is used to compute joint velocities:

$$ \dot{\mathbf{q}} = \mathbf{J}^\top(\mathbf{J}\mathbf{J}^\top + \lambda^2 \mathbf{I})^{-1} (\mathbf{x}^* - \mathbf{x}) $$

Pinocchio provides fast Jacobian computation and frame-level kinematics, enabling stable closed-loop IK control.

Motion Planning with OMPL (RRTConnect)

Motion planning is performed in joint configuration space \( \mathcal{C} \subset \mathbb{R}^7 \).

Given start and goal configurations, RRTConnect grows two trees toward each other using random sampling until a collision-free path is found:

$$ \|\mathbf{q}_{start} - \mathbf{q}_{goal}\| < \varepsilon $$

RRTConnect was chosen for its efficiency in high-dimensional spaces and suitability for single-query planning in pick-and-place tasks.

Step 2: PPO-Based Manipulation in MuJoCo

To explore adaptive behavior, a reinforcement learning environment was built in MuJoCo. The policy operates on incremental Cartesian end-effector actions rather than explicit joint targets.

The PPO objective maximizes the expected return:

$$ J(\theta) = \mathbb{E}_{\pi_\theta} \left[\sum_{t=0}^{\infty} \gamma^t r_t \right] $$

Reward shaping includes distance, success, smoothness, and safety terms:

$$ r_t = -\|\mathbf{p}_{ee} - \mathbf{p}_{obj}\| + r_{\text{success}} - \alpha \|\Delta \mathbf{a}_t\|^2 $$

PPO updates use clipped surrogate objectives with Generalized Advantage Estimation (GAE) to stabilize learning.

Next Step: Integrating IK with Learning

The current learning-based system intentionally excludes explicit inverse kinematics to isolate policy behavior.

Future work will integrate IK constraints into the learning pipeline, combining the structure of classical control with the adaptability of reinforcement learning.

  • Hybrid PPO + IK control
  • Improved stability near kinematic limits
  • More reliable grasp execution and recovery
