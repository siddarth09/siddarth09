The Problem: Robotic Manipulation Beyond Scripts

Robotic pick-and-place tasks appear deceptively simple, yet they expose many of the fundamental challenges in manipulation: high-dimensional control, kinematic constraints, perception uncertainty, and the need for precise, repeatable interaction with the environment.

Classical approaches can solve structured manipulation problems effectively, but they often require careful system integration and struggle to generalize beyond the scenarios they were explicitly designed for.

Step 1: Classical Pick & Place Pipeline

The initial system was built using a classical robotics pipeline, focusing on explicit modeling and modular system design. Each component was responsible for a clearly defined role in the manipulation process.

The pipeline integrates perception, coordinate frame transformations, motion planning, and inverse kinematics to execute deterministic pick-and- place behavior with a 7-DoF Franka Panda arm.

  • Cube detection and pose estimation
  • TF-based transformation into the robot base frame
  • Motion planning to generate task-space targets
  • Jacobian-based inverse kinematics for joint control
  • Explicit sequencing of approach, grasp, lift, and retreat

This approach provides transparency, debuggability, and precise control, making it well-suited for structured environments and repeatable tasks.

Motivation for Learning-Based Extension

While the classical pipeline performs reliably, it requires careful tuning and explicit handling of many edge cases. Small changes in object placement, timing, or execution noise can require manual intervention or redesign.

To explore more adaptive behavior, the next step was to extend the system using reinforcement learning, while keeping the problem grounded in physically realistic simulation.

Step 2: PPO-Based Manipulation in MuJoCo

A reinforcement learning environment was built in MuJoCo to study manipulation from direct interaction. Instead of relying on an external planner or IK module, the policy operates using incremental Cartesian end-effector actions.

The environment embeds Jacobian-based control internally, allowing the policy to focus on task execution rather than explicit kinematic reasoning.

  • Δ end-effector Cartesian actions with gripper control
  • Custom Gymnasium environment for Panda manipulation
  • PPO with actor–critic architecture in PyTorch
  • GAE, clipped objectives, and entropy regularization
  • Reward shaping for reach, success, safety, and smoothness

This learning-based extension enables more fluid behavior and tolerance to small variations, while remaining grounded in physically accurate dynamics.

Next Step: Integrating IK with Learning

The current learning-based system intentionally excludes explicit inverse kinematics to simplify the control interface and study policy behavior in isolation.

The next phase of this project will combine the strengths of both approaches by integrating inverse kinematics into the learning pipeline, enabling structured task constraints while retaining adaptability through learning.

  • Hybrid control combining IK constraints with PPO policies
  • Improved stability near kinematic limits
  • More reliable grasp execution and recovery

This progression reflects an ongoing exploration of how classical robotics and reinforcement learning can be composed into robust manipulation systems.
