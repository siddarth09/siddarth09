Overview

Built from first
principles

PRANA — Perception-conditioned Robotic Network with Attention — is a multimodal policy that fuses dual-camera vision, language instructions, and proprioceptive state through a unified Transformer to predict full action chunks at inference time.


Rather than adapting an existing VLA, every module was designed, implemented, and validated from scratch — from the ViT vision encoders and lightweight language embedding to the action-query readout mechanism and the LeRobot deployment harness.

Deployment
Autonomous screwdriver retrieval — physical 7-DoF platform, unstructured environment
Architecture

One sequence.
Three modalities.

Visual patch tokens, language tokens, and a single proprioceptive token are concatenated into a unified sequence. Fifty learnable action-query tokens attend over this context through a 4-layer Transformer encoder, producing an entire action horizon in a single forward pass.


This design eliminates autoregressive decoding overhead, enabling sustained 50 Hz control on a physical platform.



  • ViT-Tiny backbone — 197 patch tokens per camera, pretrained
  • 394 visual tokens from two cameras concatenated pre-attention
  • 16-token language context from PaliGemma tokenizer
  • 6-DoF state projected to a single proprioceptive token
  • 50 learnable action queries as readout mechanism
  • L1 loss with padding mask for episode boundary integrity
IMG_TABLE → ViT-Tiny → Linear → [197, 256] IMG_WRIST → ViT-Tiny → Linear → [197, 256] ↓ concat v_tokens [394, 256] LANGUAGE → Embedding (256k) → l_tokens [16, 256] STATE → Linear → s_tokens [1, 256] QUERIES → nn.Parameter → q_tokens [50, 256] sequence = [v_tokens | l_tokens | s_tokens | q_tokens] ↓ TransformerEncoder — 4 layers — 8 attention heads — dim_feedforward 1024 — norm_first (Pre-LN) ↓ output[-50:, :] ↓ Linear → GELU → Linear ↓ action_chunk [50, 6]
Training

Imitation learning
at scale

500+ human teleoperation episodes collected via LeRobot's recording infrastructure. The dataset streams natively from parquet files with a custom windowed sampler that prevents action chunks from crossing episode boundaries.


Actions, states, and visual inputs are independently normalised using per-modality mean and standard deviation. Statistics are serialised alongside the checkpoint and applied at deployment to recover physical motor radians from network outputs.

  • 500+ demonstration episodes, dual-camera multimodal
  • Action chunking: 50-step horizon per inference call
  • L1 loss with padding mask on terminal frames
  • AdamW — lr 1e-4, weight decay 1e-4
  • MEAN_STD normalisation across Visual, State, Action
  • Torchvision v2 transforms — scale to [0,1], resize 224×224
  • PaliGemma tokenizer — max_length 16, padded
  • LeRobotDataset parquet streaming — no full RAM load
Deployment

Hardware in
the loop

PranaPolicy subclasses LeRobot's PreTrainedPolicy, integrating into the native recording and evaluation stack via a lightweight factory hook — no framework fork required.


An action deque caches the full 50-step chunk on first inference. Subsequent control ticks dequeue the next action, keeping per-step latency near zero while sustaining closed-loop 50 Hz operation on the physical arm.


The system was validated on autonomous screwdriver retrieval in unstructured environments, achieving greater than 90% success across varied object positions and lighting conditions.

  • PranaPolicy extends PreTrainedPolicy (LeRobot)
  • Factory hook — zero framework modifications
  • Action deque: 50-step cache, O(1) dequeue per tick
  • Un-normalisation: raw output × std + mean → motor radians
  • Stats serialised with checkpoint, loaded at inference
  • Validated on a physical 7-DoF platform, unstructured scene
  • Task: screwdriver retrieval to target box
  • Sub-centimetre terminal precision confirmed on hardware
